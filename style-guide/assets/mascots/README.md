# Min and Max mascots

Every Min and Max SVG found in MAC sources, ready to drop into an app's `public/` folder. Usage rules (where mascots may appear, the one-pastel-panel-per-screen rule) are in [`STYLE_GUIDE.md` section 7](../../STYLE_GUIDE.md#7-illustration-and-mascot-rules).

| Folder | Source | Style |
|---|---|---|
| `site/` | monashcoding-site `public/mascot/` at `b2064ea` (also matched byte-for-byte, ignoring whitespace, by the Figma exports in the maintainer's Downloads) | Indigo arms `#5757D2`, yellow `#FFE330`, large canvases |
| `study/` | mac-study `public/mascots/` at `ec53912` | Same characters redrawn for small sizes; more poses |
| `other/` | Figma export (`Group 16.svg`), not in any repo | |

Indigo appears only inside the art; never reuse it as a UI colour.
